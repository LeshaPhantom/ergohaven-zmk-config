# Инструкция по прошивке клавиатуры

## 📝 Подготовка изменений

1. **Открой редактор раскладки**
   - Перейди на сайт: [keymap-editor](https://nickcoutsos.github.io/keymap-editor/)
   - Выбери свою клавиатуру (у тебя `velvet ve ui`)

2. **Настрой раскладку**
   - Измени клавиши под свои потребности
   - Сохрани изменения
   - *Подробная инструкция по редактору: [Ergohaven Docs](https://journey.ergohaven.xyz/pages/docs/keymap-editor)*

## ⚡ Прошивка правой половины

1. **Подготовь правую половину**
   - Подключи **правую** половину клавиатуры кабелем к компьютеру
   - Нажми кнопку сброса на правой половине

2. **Загрузи прошивку**
   - На компьютере появится диск как флешка
   - Скачай файл прошивки из редактора
   - Распакуй архив (если нужно)
   - Скопируй файл `velvet_v3_ui_right-ergohaven-zmk.uf2` на диск клавиатуры

## 🔄 Синхронизация половин

**Важно!** После копирования файла:
- Одновременно нажми кнопки сброса на **обеих** половинах клавиатуры
- Клавиатура перезагрузится и заработает с новой раскладкой
